# Gabriel Moreira — Portfolio

Site pessoal de **Gabriel Moreira**, Design Engineer especializado em IA, Product Design e experiências digitais de alta performance.

## Stack

- HTML, CSS e JavaScript (sem build step)
- Hospedagem estática via [GitHub Pages](https://pages.github.com/)

## Desenvolvimento local

Abra `index.html` no navegador ou use um servidor local:

```bash
python3 -m http.server 8080
```

Acesse [http://localhost:8080](http://localhost:8080).

## Estrutura

| Arquivo / pasta | Descrição |
|-----------------|-----------|
| `index.html` | Página principal |
| `styles.css` | Estilos |
| `app.js` | Interações e i18n |
| `assets/` | Imagens, logos e cases |
